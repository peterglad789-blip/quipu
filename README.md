# QUIPU · Kervin Space Programs
NASA Space Apps Challenge 2026 · Interplanetary Survival Guide: Martian Map

Open `index.html` from a web host (GitHub Pages, Netlify, Vercel). It does not work by double-clicking the file, because the browser blocks local data files.

## Data credits
- NASA Mars Trek / Moon Trek imagery (Viking, MOLA, THEMIS, CTX, LRO WAC)
- NASA/JPL Mars 2020 waypoints feed (assets/traverse.json)
- Jezero terrain: HiRISE DTM (USGS/JPL/University of Arizona) + MGS MOLA, quantized-mesh tiles from the open project https://github.com/enomis-dev/perseverance-traverse-3d
- Perseverance 3D model: NASA 3D Resources (https://github.com/nasa/NASA-3D-Resources)
- NASA DONKI, JPL planetary elements, NSSDC fact sheets, NASA GISS Mars24
- 3D engine: CesiumJS (Apache 2.0)
